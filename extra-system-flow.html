01 — System Scope

The Context Diagram

One box, six relationships. Before looking inside the system, this is everything it touches — hover a party to see what it sends in and what it gets back.

data flowing back out

Customer

Browses, orders and pays — online or in a branch — then receives order confirmation and live delivery updates.

Branch Staff

Checks live stock and price before every sale, and records each transaction the moment it happens.

Warehouse Manager

Feeds in new shipments and reacts to automatic low-stock alerts instead of waiting for a branch to run out.

Delivery Company

Receives the delivery request and pushes tracking status back, so nothing is tracked by email guesswork anymore.

Payment Gateway

Processes card and online payments and returns a confirmation before any order is finalised.

Branch Manager

Approves price overrides and pulls sales & stock reports straight out of the system — no more Excel reconciliation.
